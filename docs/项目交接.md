## 0. 一句话

ESP32-P4 独立终端：局域网从泰山派 Hub 汇聚多台设备状态，一屏看多台，按键切换明细；
**只读，不下发控制**。被监控节点为 `taishan-3m` 与 `windows-main`，`cloud-main` 预留未接入。

## 3. 固件结构

```text
firmware/esp32-terminal/
├── sdkconfig.defaults     # 关键配置固化（broker 地址/账号/端口、LVGL、分区）
├── sdkconfig.secrets      # 真实 MQTT 密码，chmod 600，绝不入库
├── build-s2a.sh           # 构建：叠加 secrets + 校验密码已编入（名字延用）
├── partitions.csv         # factory @0x20000，app 4 MB
├── tools/gen_cjk_font.sh  # 扫 main/ 里的中文字符串 → 生成 3 个字号字体
├── components/            # vendored（BSP 5.2.3、esp_lvgl_port 2.9.0、LCD/触摸驱动）
├── managed_components/    # 组件管理器下载（lvgl 9.6、esp_lcd_ek79007 2.0.2）
└── main/
    ├── main.c                 # 板信息日志 → 显示 → 建 UI → 背光 → 网络/MQTT → 解析器挂回调
    ├── app_ui.c/.h            # 状态栏（含全设备汇总状态灯）+ 页签 + 通用控件
    ├── app_ui_internal.h      # 配色、控件句柄表、槽位与跨页声明
    ├── ui_page_overview.c     # 总览页：4 张设备摘要卡 + 网络卡 + MQTT 卡
    ├── ui_page_monitor.c      # 监控页：◀ ▶ 切设备 + 5 张卡（能力自适应）
    ├── ui_page_placeholder.c  # 设置页占位
    ├── eth_link.c/.h          # 后台装 EMAC + IP101 + DHCP，只读快照给 UI
    ├── mqtt_link.c/.h         # 三级地址解析、自管重连、多回调分发
    ├── device_registry.c/.h   # device_id → 固定槽位 0..3（首次出现即固定）
    ├── device_metrics.c/.h    # 解析 metrics（schema 1–4），按槽位存快照
    ├── device_status.c/.h     # 解析 status（含 LWT），实现在线判定
    └── fonts/                 # cjk_16/20/28（生成物，入库，否则别人编不出来）
```

初始化顺序不能乱：`device_registry_init()` → `device_metrics_init()` → `device_status_init()`，
且都在开始收包前完成；消息不缓存，晚初始化就丢帧。

**以太网要点**（`eth_link.c`，原理图 v1.5.2，与 IDF P4 默认一致）：

| 信号 | GPIO | 信号 | GPIO |
|---|---|---|---|
| MDC | 31 | TXD0 | 34 |
| MDIO | 52 | TXD1 | 35 |
| PHY_RSTN（低有效） | 51 | CRS_DV | 28 |
| RMII_CLK（IP101→P4，50 MHz） | 50 | RXD0 | 29 |
| TX_EN | 49 | RXD1 | 30 |

PHY 地址 **1**；IP101 自带 25 MHz 晶振并向 P4 输出 50 MHz，时钟方向必须是
`EMAC_CLK_EXT_IN`（选 `EMAC_CLK_OUT` 会两边同时推时钟）。启动只 `xTaskCreate`，PHY 复位、
自协商、DHCP 全在后台，UI 只读快照，绝不等待网络。

## 4. 数据能力（协议 schema 1–4）

| 字段组 | 泰山派 | Windows | 屏幕上的落点 |
|---|---|---|---|
| cpu（利用率、负载、核数） | ✅ 8 核 + load1/5/15 | ✅ 10 物理 / 16 逻辑 | 大卡左列、负载卡 |
| memory | ✅ | ✅ | 内存卡 |
| temperature（soc + zones） | ✅ 6 温区 | ❌（`null`） | 右侧温区卡（回退） |
| disk + disks[] | ✅ 仅 `/` | ✅ C: 主 + D:/S: 分区 | 磁盘卡 |
| gpu | ❌ | ✅ 4060 Laptop：利用率/温度/显存 | 大卡右列（GPU 列） |
| processes / process_count | ❌ | ✅ 前 3，按内存降序 | 右侧进程卡 |
| network | ❌ | ✅ 收发速率 | 左下网络卡 |
| services | ✅ mosquitto | ✅ W32Time | 已从两页删除（不再上屏） |
| containers / container_count | ✅（schema 4） | ❌ | 大卡右列（容器列） |
| uptime | ✅ | ✅ | 负载卡标题可切「运行时长」 |

协议权威定义见 `../protocol/topics-v1.md`（v4 段）。Linux 端发 schema 4，Windows 端仍发 3；
ESP32 两端都收。

## 5. 界面现状（1024×600，深色，全中文）

- **总览**：4 张 222×260 设备摘要卡（未接入灰显「未接入设备」，不写「离线」）+
  网络卡 + MQTT 卡；状态灯是**全部在线才绿**的汇总结论。
- **监控**：页头 ◀ ▶ + 设备名/协议 id + 右侧四种状态（数据在线/已过期/设备离线/等待数据）。
  五张卡固定坐标，卡面按能力二选一：
  1. `480×240` CPU 大卡：左列 CPU；右列有 GPU 显示利用率/温度/显存，没有 GPU 显示
     「运行容器」（绿点 + 服务名，最多 4 条）。
  2. `464×240` 右侧卡：有进程数据显示进程（名称 / CPU / 内存，按内存排序）；没有进程数据显示温区（3×2）。
  3. `304×140` 左下：有网速显示网络（IP + ↓/↑ 速率）；没有则显示平均负载 / 运行时长。
  4. `304×140` 内存卡；`320×140` 磁盘卡（主分区大字 + 其余分区小字）。
- 所有缺失字段一律 `--` + 一句原因（等待 Hub 数据 / 数据已过期 / 未上报），**不拿 0 冒充**。

## 6. 已知坑（别再踩）

1. **枚举重名**：IDF 的 `ETH_LINK_UP/DOWN` 已存在，本项目统一用 `ETH_STATE_*`。
2. **触摸设备**：定时器回调里 `lv_indev_active()` 恒为 `NULL`，必须用 `bsp_display_get_input_dev()`。
3. **改 `sdkconfig.defaults` 不生效**：必须删掉 `sdkconfig` 再构建（`build-s2a.sh` 已按时间戳处理）。
4. **烧录地址**：分区表 **0x9000**、app **0x20000**（旧 hello_p4 是 0x8000/0x10000）。
5. **kconfig 字符串要带引号**：`sdkconfig.secrets` 写成 `…="abc"`，否则静默回退默认值，现象是“烧录成功但连不上”。
6. **构建必须叠加 secrets**：`SDKCONFIG_DEFAULTS="sdkconfig.defaults;sdkconfig.secrets"`（脚本已做）。
7. **中文与字体**：不能用 Montserrat；新增中文后重跑 `tools/gen_cjk_font.sh`，脚本靠 `--lv-include lvgl.h`
   才能编过；它扫的是**字符串字面量**，注释里的字不算。
8. **注释里不能出现 `*/`**：曾在注释写 `devices/*/metrics`，提前结束块注释，报一堆 unknown type。
9. **cJSON 不要 memcpy 到栈**：esp-mqtt 任务栈只有 6 KB，用 `cJSON_ParseWithLength(data, data_len)`。
10. **`lv_obj_remove_style_all()` 只用在叶子控件**：容器上会把 size/flex 样式一起删掉（页面缩成默认尺寸、
    按钮叠在一起）。
11. **显隐仍用 flag**：这份 LVGL 9.6 没有 `lv_obj_set_hidden`，用 `lv_obj_add_flag/remove_flag(HIDDEN)`。
12. **事件回调里只改状态，不重建控件**：◀ ▶ 只改 `s_mon_slot` 再手动刷新一次。
13. **槽位分配后不变**，指标/状态共用同一下标，否则会出现「名字是 A、数据是 B」。
14. **`UI_DEVICE_SLOTS` 必须等于 `DEVICE_REGISTRY_MAX_DEVICES`**，编译器不会帮你查。
15. **static 函数前向声明不能省**（`btn_prev_cb` 调后面定义的 `monitor_poll_cb`）。
16. **Windows 侧读 `\\wsl.localhost` 会失败**：固件先复制到 `C:\Users\haha4\p4-s0\` 再烧。
