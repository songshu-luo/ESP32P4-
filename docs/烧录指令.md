## 一、当前固件（S1 以太网 · 修订 3）

固件已从 WSL 复制到 Windows 本地，**不经过 `\\wsl.localhost` 路径**，避免 esptool 读路径失败。

| 文件 | 本地路径 | 烧录地址 |
|---|---|---|
| bootloader.bin | `C:\Users\haha4\p4-s0\bootloader.bin` | 0x2000 |
| partition-table.bin | `C:\Users\haha4\p4-s0\partition-table.bin` | **0x9000** |
| esp32_terminal.bin | `C:\Users\haha4\p4-s0\esp32_terminal.bin` | **0x20000** |

> 注意：这两个地址和旧 `hello_p4` 工程不一样（旧的是 0x8000 / 0x10000）。
> 本工程用的是官方 BSP 布局，分区表在 0x9000。

### 本版变更（修订 3 · S1）

**新增板载以太网（IP101GRI + ESP32-P4 EMAC RMII + RJ45）。**

- 界面最下方多了一张 `NETWORK` 卡片，显示链路状态和大字 IP。
- 网络在独立后台任务里初始化，**不阻塞开机**：屏幕先亮，网线插好后状态自己变。
- 引脚：MDC=31 / MDIO=52 / PHY_RST=51 / RMII_CLK_IN=50 /
  TXEN=49 / TXD0=34 / TXD1=35 / CRS_DV=28 / RXD0=29 / RXD1=30，PHY 地址 1。

**这一版要看的三件事：**

1. 底部卡片最初可能是 `NO LINK`（黄色）→ 说明驱动装好、在等网线。
2. 网线插到**路由器/交换机**（不是电脑直连）后，几秒内变 `LINK UP` → 再等几秒变
   `ONLINE`（绿色）并显示 `192.168.x.x` 这样的地址。
3. 串口日志出现 `eth_link: link up: 100 Mbps, full duplex` 和
   `eth_link: got ip 192.168.x.x  gw ...`。

**如果一直是 `NO LINK`：** 网线/对端问题，先确认网口灯。
**如果显示 `ETH ERROR`：** 卡片上会直接写出错误名（如 `ESP_ERR_TIMEOUT`、`ESP_FAIL`）。

## 五、重新编译后同步固件到 Windows

每次 WSL 里 `idf.py build` 之后，都要重新复制一次，否则烧的是旧文件。

在 **WSL 终端**执行：

```bash
cd ~/esp32_workspace/"Smart terminal"/firmware/esp32-terminal
B=build; D=/mnt/c/Users/haha4/p4-s0
cp $B/bootloader/bootloader.bin $B/partition_table/partition-table.bin $B/esp32_terminal.bin $D/
sha256sum $D/*.bin
```

`sha256sum` 的输出可以用来对照，确认复制的是最新固件。

## 六、常见报错

| 报错 | 原因 | 处理 |
|---|---|---|
| `Missing argument '<address> <filename>...'` | 多行命令的续行符 `` ` `` 漏了，命令被截断 | 用第一节的单行版 |
| `could not open port COM5` | 串口被 miniterm / 串口监视器占用 | 先关掉 miniterm |
| `Wrong boot mode detected` | 板子没进下载模式 | 按板上的 BOOT 键再点 RESET，或直接重试 |
| 烧录成功但屏幕全黑 | 背光/供电/MIPI 问题 | 看串口日志有没有 `bsp_display_start() failed` |
