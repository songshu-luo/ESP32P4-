涵盖：泰山派 Hub、板端指标 Agent、Windows Agent、ESP32 配置与烧录、常用诊断命令。
装机流程都可重复执行；**凭据只显示变量名，不要把值打印到对话或文档里**。

## 2. 泰山派 Hub 部署

源码在 `services/taishan-hub/`，两个幂等脚本：已存在的凭据不会被覆盖。

```bash
cd ~/esp32_workspace/"Smart terminal"
rsync -a services/taishan-hub/ lckfb@192.168.0.156:/home/lckfb/taishan-hub/
ssh lckfb@192.168.0.156 'sudo -n bash /home/lckfb/taishan-hub/install-broker.sh'
ssh lckfb@192.168.0.156 'sudo -n bash /home/lckfb/taishan-hub/install-agent.sh'
```

落盘位置：

| 内容 | 路径 |
|---|---|
| Mosquitto 附加配置 | `/etc/mosquitto/conf.d/taishan-hub.conf` |
| 全部凭据（勿打印） | `/etc/taishan-hub/credentials.env`（root:lckfb 640） |
| 口令 / ACL | `/etc/taishan-hub/mosquitto.passwd`、`mosquitto.acl`（mosquitto:mosquitto） |
| Agent 源码 | `/opt/taishan-hub/agent/{agent,config,metrics}.py` |
| Agent 配置 | `/etc/taishan-hub/agent.env` |
| Agent 单元 | `taishan-hub-agent.service`（enabled，`Restart=always`） |

**账号与权限（实测）**

| 账号 | 权限 |
|---|---|
| `taishan-agent` | 只写 `hub/v1/devices/taishan-3m/{status,metrics}` |
| `esp32-terminal` | 读 `hub/v1/devices/#`、`hub/v1/events`；写 `hub/v1/commands/results/#` 和自己的两个主题；**不可读 `$SYS`** |
| `ops` | 读写全部 + `$SYS/#` |
| 匿名 | 拒绝 |

> ACL 排查看不出问题时，记得用 **MQTT 5**：3.1.1 下越权发布会被**静默丢弃**，客户端毫无提示。

**口令文件属主坑**：`mosquitto_passwd` 要求 root:root，守护进程要求 mosquitto:mosquitto。
先在临时文件生成，再 `install -o mosquitto -g mosquitto` 替换；`/etc/taishan-hub` 目录必须 755。

## 3. 板端 Agent

- 发布节奏：metrics **2 s**、status **5 s**；容器 `docker ps` **15 s**；温度 5 s；磁盘 30 s。
- 协议 schema：**4**（比 Windows 多 `containers` / `container_count`）。
- 只读 `/proc`、`/sys` 与只读命令，不依赖 psutil；缺字段返回 `null`，不拿 0 冒充。
- 容器读取用 `docker ps --format`（约 30–60 ms），读不到 docker（未装/未起/无权限）时
  `container_count=null`，不影响其它字段。

```bash
journalctl -u taishan-hub-agent -f          # 日志
sudo systemctl restart taishan-hub-agent    # 重启
sudo tail -f /var/log/mosquitto/mosquitto.log
```

改监控服务清单：编辑 `/etc/taishan-hub/agent.env` 的 `HUB_SERVICES` 后重启（屏幕上该卡已移除，
但字段仍在协议里）。验收脚本：

```bash
python services/taishan-hub/verify/verify_from_wsl.py   # 结尾应为「结果：PASS」
```

## 4. Windows Agent

| 项目 | 值 |
|---|---|
| 安装目录 | `C:\Users\haha4\taishan-hub-agent`（`windows_agent.py`、`config.py`、`metrics.py`） |
| 配置 | `C:\ProgramData\taishan-hub\windows-agent.env` |
| 日志 | `C:\ProgramData\taishan-hub\logs\windows-agent.log` |
| 自启 | 计划任务 `TaishanHubWindowsAgent`（AtLogOn） |
| Python | `D:\path\python\Python311`（PATH 里的 `python.exe` 是沙盒运行时，缺 paho） |

```powershell
C:\Windows\System32\schtasks.exe /End /TN TaishanHubWindowsAgent
C:\Windows\System32\schtasks.exe /Run /TN TaishanHubWindowsAgent
Get-Content C:\ProgramData\taishan-hub\logs\windows-agent.log -Tail 5
```

采集口径与已知限制：

- CPU：`Get-Process` 累计 CPU 时间差分（10 s），进程按**内存降序**取前 3；物理核用
  `GetLogicalProcessorInformationEx` 按 record Size 遍历（固定步长会把 10 核读成 30）。
- 网速：`netstat -e` 累计字节差分；带 `CREATE_NO_WINDOW` 时输出是 **OEM 代码页**，
  必须 `encoding="oem"`，按 UTF-8 解会得到乱码「字节」。
- GPU：`nvidia-smi` 5 s（约 60 ms）；无风扇数据——笔记本风扇走 EC 私有通道，
  `Win32_Fan` 为空、`nvidia-smi fan.speed=[N/A]`，宁可不显示也不报假转速。
- schema **3**（无 containers）。

安装脚本 `install-windows.ps1` 是无 BOM UTF-8 时会被 PowerShell 5.1 按 ANSI 误读，
仓库里的副本已转 **UTF-8 with BOM**；改脚本后别丢 BOM。

## 5. ESP32 配置与烧录

配置在 `sdkconfig.defaults`（broker 地址/端口/账号）+ `sdkconfig.secrets`（密码，chmod 600，不入库）。
构建必须用脚本，否则密码是空串：

```bash
bash build-s2a.sh    # 叠加 secrets + 校验密码已编入
```

烧录（Windows，**单行**）：

```powershell
python -m esptool --chip esp32p4 -p COM5 -b 460800 --before default-reset --after hard-reset write-flash --flash-mode dio --flash-freq 80m --flash-size 16MB 0x2000 C:\Users\haha4\p4-s0\bootloader.bin 0x9000 C:\Users\haha4\p4-s0\partition-table.bin 0x20000 C:\Users\haha4\p4-s0\esp32_terminal.bin
```

| 文件 | 地址 | 说明 |
|---|---|---|
| bootloader.bin | `0x2000` | 改分区/IDF 版本才需要重烧 |
| partition-table.bin | `0x9000` | 改分区表必须一起烧 |
| esp32_terminal.bin | `0x20000` | 日常只烧这一段 |

其他命令：

```powershell
python -m serial.tools.miniterm COM5 115200   # 看日志，Ctrl+] 退出
python -m esptool --chip esp32p4 -p COM5 -b 460800 erase-flash   # 黑屏/不启动时清空
python -m esptool --chip esp32p4 -p COM5 chip-id
python -m esptool --chip esp32p4 -p COM5 flash-id
```

常见报错：

| 报错 | 原因 | 处理 |
|---|---|---|
| `Missing argument '<address> <filename>...'` | 续行符 `` ` `` 漏了 | 用单行命令 |
| `could not open port COM5` | 串口被 miniterm 占用 | 先退出串口工具 |
| `Wrong boot mode detected` | 没进下载模式 | 按 BOOT 再点 RESET，或重试 |
| 烧录成功但黑屏 | 背光/供电/MIPI | 看日志是否 `bsp_display_start() failed` |

## 6. 诊断速查

```bash
# 在板子上订阅一条 retained 指标（凭据从 env 读，不打印）
sudo bash -c 'set -a; . /etc/taishan-hub/credentials.env; set +a; \
  mosquitto_sub -V mqttv5 -h 127.0.0.1 -u "$ESP32_USER" -P "$ESP32_PASS" \
  -t hub/v1/devices/taishan-3m/metrics -C 1'
```

| 想确认 | 看什么 |
|---|---|
| 设备在不在 | `status` 的 `state` + `valid_for_seconds`（15 s） |
| 数据新不新 | `metrics` 的 `valid_for_seconds`（8 s），屏幕上变灰即过期 |
| 容器有没有上报 | `container_count`（`null` = 读不到 docker，不是没有容器） |
| 进程/网速/多分区 | 只有 Windows 端有；Linux 端对应卡自动回退 |
| 网络是否通 | ESP32 日志 `got ip …`；板端 `ping 192.168.0.100` |
| 地址变了 | 路由器 DHCP 保留（待做）；泰山派、ESP32 都要保留 |
