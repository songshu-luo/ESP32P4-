> 日期：2026-11-19
> 阶段：S0（点屏 + 触摸 + 背光）

## 1. 实机信息（esptool 实测）

| 项目 | 值 |
|---|---|
| 芯片 | ESP32-P4，**revision v1.3**（旧版，< v3.0，非 P4X）|
| 特性 | Dual Core + LP Core，400 MHz |
| Crystal | 40 MHz |
| Flash | **16 MB**（Manufacturer 0xC8 / Device 0x4018）|
| USB 模式 | USB-Serial/JTAG，Windows 侧 COM5 |
| MAC | 30:ed:a0:e2:23:6f |

**结论：** 必须启用 `CONFIG_ESP32P4_SELECTS_REV_LESS_V3=y`。已写入 `sdkconfig.defaults` 固化。

## 4. 关键配置

```c
CONFIG_IDF_TARGET="esp32p4"
CONFIG_ESP32P4_SELECTS_REV_LESS_V3=y     // rev v1.3 必须
CONFIG_ESPTOOLPY_FLASHSIZE_16MB=y
CONFIG_PARTITION_TABLE_OFFSET=0x9000      // 与官方 BSP 示例一致
CONFIG_BSP_SELECT_ESP32_P4_FUNCTION_EV_BOARD=y
CONFIG_BSP_LCD_TYPE_1024_600=y            // EK79007 + GT911
CONFIG_SPIRAM_MODE_HEX=y
CONFIG_SPIRAM_SPEED_200M=y
CONFIG_LV_USE_PERF_MONITOR=y              // 右上角显示 FPS / CPU
```
