# S2-d 页面骨架（总览 / 监控 / 设置）

状态：**已实机验收通过**（2026-11-19）
固件：`0.5.3-s2d`，tag `s2d-verified`

## 1. 这一步做了什么

屏幕从「一屏到底」改成**顶部常驻状态栏 + 三页页签**：

```
┌──────────────────────────────────────────────────────────────┐
│ ● 在线   总览                                    固件 0.5.3-s2d │  ← 状态栏 56 px
├──────────────────────────────────────────────────────────────┤
│  总览   │  监控   │  设置                                       │  ← 页签 56 px
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                    当前页面内容 1024 × 488                    │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

- **状态栏**：在线灯 + 状态文字 + 当前页面名 + 右上角固件版本。
  `clock_synced=false` 时中间出现黄色提示「该设备时间未同步，过期判断不可信」
  （协议 §4.1 的硬性要求，S2-c 遗留项在这里补上）。
- **页签**：LVGL `lv_tabview`，点按钮和左右滑动都能切页，不需要自己写手势。
- **总览页**：CPU / 内存 / 主控温度 / 磁盘 四张指标卡 + 网络卡 + MQTT 卡。
- **监控页**：6 个温区（3×2 网格）、systemd 服务、负载 1/5/15、内存/交换、磁盘。
- **设置页**：占位页，写明「修改 broker 地址、凭据与设备参数需要固件重配」。
  **故意做成说明文字，不做假按钮**。

### 控制页已移除

上一版骨架计划里是「总览 / 监控 / **控制** / 设置」四页。按需求决定：
**这块板子只做「查看状态」，不提供任何控制入口**。控制页连同相关字段全部删除，
设置页也明确说明不提供服务端写入。

因此 `docs/项目交接.md` §7 的安全红线在当前固件上**没有被触碰**：
固件里没有任何命令下发路径，`hub/v1/commands/*` 只出现在协议文档里。

## 3. 设计决策

### 3.1 状态灯放在状态栏，不放指标区

状态灯描述的是「链路 + 设备」，不属于任何一页。放状态栏之后，切到监控页
也看得到，不用每页复制一份。

### 3.2 三态判定顺序不变

仍然是 S2-c 的五级优先级（MQTT 不通 → 未知，then online/offline/过期/未知），
只是把结果画到状态栏。**链路断了一律「未知」，绝不沿用缓存里的绿色。**

### 3.3 字段缺失 = `--`，不显示 0

`has_*` 标志的纪律在监控页继续执行：温区没上报、swap 不存在、
服务列表为空，都显示灰色 `--` / `未上报`，不用 0 冒充。

### 3.4 体积

自定义分区表把 app 提到 4 MB（`partitions.csv`，factory @ `0x20000`）。
当前 app **0x16f790（1,505,168 B）已用，剩余 64%（约 2.6 MB）**，
后续加页面不再受 1500 K 限制。

## 4. 验收清单

1. 开机后顶部状态栏左侧灯变绿、文字「在线」，中间显示「总览」。
2. 三个页签都能点，左右滑动也能切；**切页时状态栏中间的页面名跟着变**。
3. 总览页四张卡有真实数值；监控页 6 个温区、负载三个数、内存/交换、磁盘都在动。
4. 服务卡显示 `mosquitto` 且状态是中文（运行中）。
5. 设置页是说明文字，没有任何可点的按钮。
6. 串口日志仍打印 `app_main: S2-c status lamp ready - backlight 80%`
   （这行字是 S2-c 留下的，S2-d 没跟着改；功能无影响，S2-e 一并更新）。
